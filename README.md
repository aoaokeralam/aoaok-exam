# AOAOK Departmental Test Exam Portal

A sleek, clutter-free, single-screen landing page for the **Association of Agricultural Officers Kerala (AOAOK)**, featuring the official AOAOK emblem and a major direct link to the **Exam Portal**. Designed for instant deployment on **GitHub Pages**.

---

## 🌟 Key Highlights

- **Zero Clutter, No Scrolling Needed**: Fits neatly on a single screen across desktop, tablet, and mobile.
- **Official AOAOK Emblem**: High-resolution circular logo with the agricultural palm, paddy, and microscope emblem.
- **Major Exam Portal CTA**: Glowing, high-contrast action button (**"ENTER EXAM PORTAL"**) directing officers straight to the test platform.
- **Core Subject Tags**: Kerala Service Rules (KSR), Kerala Finance Code (KFC), and Kerala Treasury Code (KTC).
- **Zero-Build Static Architecture**: Pure HTML5, Tailwind CSS (via CDN), and Lucide icons. Runs directly in any browser with no dependencies.

---

## ⚙️ How to Set Your Exam Portal URL

Open [`index.html`](index.html) and update line 46:

```javascript
// ⚙️ Change this to your live exam portal URL:
const EXAM_PORTAL_URL = "https://your-exam-portal-url.com";
```

*(You can also click "Configure Portal URL" in the footer to test or enter a link directly in the browser).*

## 🚀 How to Host on GitHub Pages (Step-by-Step)

### Option 1: Via GitHub Web Interface
1. Go to [GitHub.com](https://github.com/new) and create a repository (e.g., `aoaok-exam-portal`).
2. Upload the files from `C:\Users\rajuv\.gemini\antigravity\scratch\aoaok-portal`:
   - `index.html`
   - `README.md`
   - `assets/logo.png`
3. Commit the changes.
4. Go to **Settings** &rarr; **Pages** &rarr; Under **Branch**, select `main` and `/ (root)` &rarr; Click **Save**.
5. Your website will be live in 1–2 minutes at:  
   `https://<your-username>.github.io/<repository-name>/`
